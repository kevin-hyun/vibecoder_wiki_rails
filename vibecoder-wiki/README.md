# 바이브코더 위키 🌟

> 30-40대 비전공자를 위한 쉬운 IT 개념 설명 플랫폼

## 🎯 프로젝트 개요

바이브코더 위키는 비전공자가 IT 개념을 쉽게 이해할 수 있도록 돕는 커뮤니티 기반 위키입니다. 일상적인 비유와 친근한 설명으로 복잡한 IT 용어를 설명합니다.

## ✨ 주요 기능

### 🔥 실시간 협업 위키
- **동시 편집 가능**: Supabase PostgreSQL로 동시성 문제 해결
- **실시간 알림**: 새로운 설명이나 투표가 즉시 반영
- **실시간 투표**: 도움됨/어려움 투표 결과 실시간 업데이트

### 📚 비전공자 친화적 설명
- **300자 제한**: 간결하고 이해하기 쉬운 설명
- **일상 비유**: 복잡한 개념을 일상의 예시로 설명
- **난이도 표시**: ⭐~⭐⭐⭐로 쉬운 난이도 구분

### 🎮 게이미피케이션 시스템
- **포인트 획득**: 설명 작성, 투표 참여시 포인트 적립
- **레벨 시스템**: 🌱새싹 → 👑마스터까지 성장
- **베스트 설명**: 커뮤니티 투표로 선정되는 최고의 설명

### 🔍 스마트 검색
- **한글+영어 통합 검색**: "API" 또는 "에이피아이" 모두 검색 가능
- **PostgreSQL Full-text Search**: 빠르고 정확한 검색
- **카테고리 필터**: IT기초, 창업, UI/UX, 비즈니스별 분류

## 🛠 기술 스택

### Backend
- **Ruby on Rails 7.2**: 메인 프레임워크
- **PostgreSQL (Supabase)**: 실시간 데이터베이스
- **Supabase Realtime**: 실시간 기능
- **Devise**: 사용자 인증 (Google OAuth 지원)
- **ActionCable + Redis**: 실시간 알림

### Frontend  
- **Tailwind CSS**: 반응형 UI 스타일링
- **ViewComponent**: 재사용 가능한 컴포넌트
- **Stimulus + Turbo**: 모던 JavaScript 상호작용
- **Hotwired**: 페이지 새로고침 없는 부드러운 UX

### Database Features
- **UUID 기본키**: 보안과 확장성
- **JSONB 메타데이터**: 유연한 데이터 구조
- **Full-text Search**: 한국어 검색 최적화
- **Connection Pooling**: 동시 접속 최적화

## 🚀 빠른 시작

### 1. 환경 설정
```bash
# 저장소 클론
git clone <repository-url>
cd vibecoder-wiki

# 환경변수 설정
cp .env.example .env
# .env 파일에 Supabase 정보 입력
```

### 2. 설치 및 실행
```bash
# 의존성 설치
bundle install

# 데이터베이스 생성 및 마이그레이션
rails db:create
rails db:migrate
rails db:seed

# 서버 시작
rails server
```

### 3. 접속
- 개발 서버: http://localhost:3000
- 관리자 계정: admin@vibecoder.wiki / password123!
