바이브코더 위키 - 프로젝트 기획문서

1. 프로젝트 개요
   1.1 서비스 정의
   "바이브 코딩 입문자를 위한 집단지성 기반 IT/창업 개념 학습 플랫폼"

1.2 핵심 가치
쉬운 설명: 커뮤니티가 투표로 검증한 가장 이해하기 쉬운 IT 개념 설명
게이미피케이션: 설명 작성과 투표를 통한 재미있는 학습 경험
스펙 인증: 기여도를 공식 인증받아 포트폴리오로 활용 가능
1.3 타겟 사용자
주요 타겟: 30-40대 비개발자 바이브 코딩 입문자
특징: IT 개념을 처음 접하지만 자신만의 서비스를 만들고 싶어하는 사람들 2. 핵심 기능
2.1 IT 개념 설명 시스템
사용자들이 IT 개념에 대한 쉬운 설명을 작성
커뮤니티 투표로 베스트 설명 선정
캐러셀 형태로 인기 설명 순서대로 표시
2.2 UI 컴포넌트 가이드
실제 UI 컴포넌트를 시각적으로 보여주며 설명
인터랙티브 모드: 마우스 오버시 컴포넌트 이름 표시
문서 모드: 깔끔한 리스트 형태로 전환 가능
2.3 게이미피케이션 요소
투표 시스템 (👍 도움됐어요 / 👎 어려워요)
작성자 뱃지 및 레벨 시스템
베스트 설명 작성시 포인트 획득
2.4 프리미엄 "바이브 마스터" 시스템
월 9,900원 구독 모델
프로필 커스터마이징 (배지, 애니메이션 효과)
공식 인증서 발급 기능
LinkedIn 연동 가능한 포트폴리오 3. 기술 스택
3.1 백엔드 (Rails 7.2)

- Framework: Ruby on Rails 7.2
- Language: Ruby 3.2+
- Database: SQLite3 (Litestack 최적화)
- Authentication: Devise + Google OAuth
- Template Engine: ERB + ViewComponent
- Background Jobs: Sidekiq (Redis)
- File Upload: Active Storage

3.2 프론트엔드

- Styling: Tailwind CSS
- JavaScript: Stimulus + Turbo (Rails 7 기본)
- Components: ViewComponent
- Carousel: Swiper.js
- Icons: Heroicons
- 반응형: Tailwind Responsive

3.3 배포 및 인프라

- Hosting: Railway / Heroku (Rails 특화)
- Database: SQLite3 (Production) - Litestack
- Caching: Redis
- Domain: 커스텀 도메인
- Analytics: Google Analytics
- Monitoring: Rails 내장 로깅 + Sentry

4. 데이터 구조 (Rails ActiveRecord)
   4.1 Rails 모델 구조
   
   concepts (개념)
   ```ruby
   class Concept < ApplicationRecord
     # 비전공자를 위한 필드
     # title: string - "API", "Git" 등 쉬운 용어
     # simple_definition: text - 한 문장 정의
     # description: text - 상세 설명
     # category: string - 'it', 'startup', 'ui', 'business'
     # level: integer - 1(초급), 2(중급), 3(고급)
     # why_important: text - 왜 알아야 하는지
     # is_verified: boolean - 관리자 검증
     # is_popular: boolean - 인기 개념
     # view_count: integer
     # created_by: string (User ID)
   end
   ```
   
   explanations (설명)
   ```ruby
   class Explanation < ApplicationRecord
     # 쉬운 설명을 위한 필드
     # concept_id: string
     # author_id: string  
     # content: text - 설명 내용 (300자 제한)
     # simple_analogy: text - 일상 비유
     # example: text - 구체적 예시
     # difficulty_level: string - 'beginner', 'intermediate', 'advanced'
     # tags: json - ["일상비유", "초보추천"] 
     # vote_count: integer
     # helpfulness_score: integer - 도움됨 점수
     # clarity_score: integer - 명확성 점수
     # is_best_explanation: boolean
   end
   ```
   
   users (사용자)
   ```ruby
   class User < ApplicationRecord
     # Devise 인증 + 비전공자 친화적 필드
     # email, encrypted_password (Devise 기본)
     # display_name: string
     # photo_url: string
     # is_premium: boolean - 바이브 마스터 여부
     # premium_expires_at: datetime
     # role: string - 'user', 'premium', 'admin'
     # explanations_count: integer
     # total_votes: integer  
     # concepts_contributed: integer
     # theme: string - 'light', 'dark', 'system'
   end
   ```
   
   votes (투표)
   ```ruby
   class Vote < ApplicationRecord
     # 비전공자 친화적 투표 시스템
     # user_id: string (nullable - 비로그인 투표 허용)
     # explanation_id: string
     # vote_type: string - 'helpful' or 'difficult'
     # reason: string - 투표 이유
     # ip_address: string - 비로그인 사용자 식별용
   end
   ```

.env

RAILS_MASTER_KEY=your_master_key_here
